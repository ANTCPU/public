# SETUP — antcpu Local Environment

Get running in 5 steps.

## Requirements
- Node.js v18+
- npm v9+
- Git

## Steps

1. Clone — git clone https://github.com/ANTCPU/antcpu-launcher-public.git
2. Install — npm install
3. Configure — cp .env.example .env.local then fill in your keys
4. Start — node server.js
5. Open — http://localhost:3000

## Notes
- SQLite DB auto-creates on first run
- All API keys optional — server runs in stub mode without them
